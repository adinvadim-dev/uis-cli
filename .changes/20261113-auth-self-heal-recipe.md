## Что нового

- Навык UIS получил рецепт самовосстановления приватной сессии: одно обновление с длинным таймаутом, один вход при неудаче, повтор того же чтения и точный следующий шаг для человека вместо общей эскалации.

The UIS skill now ships the private-session self-heal recipe that was previously only in the installed release: one long refresh, one login fallback, a re-read of the failing command and an exact human step when still blocked.
