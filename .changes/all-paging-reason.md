`calls search --source private --all` now pages by `communication_id asc` when `--sort` is omitted, so large days no longer fail on repeated call IDs. When a bounded export still fails because the call set moved, JSON output names the reason in `error.details.reason` (`population_changed`, `repeated_communication_id`, `count_mismatch`, `short_page`) with a retry hint instead of a bare `capability_unavailable`.
